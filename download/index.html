If Windows says it protected your PC

Rootwork isn't signed with a paid certificate, so the first time you open the installer Windows doesn't recognise it and puts up a blue box. It's a warning about the publisher being unknown, not about anything found in the file.

Windows protected your PCMicrosoft Defender SmartScreen prevented an unrecognised app from starting.

Run anywayDon't run
  1. Choose More info, the small link under the message.
  2. Choose Run anyway.
  3. The installer opens. It takes about a minute.

Which Windows do I have?

Open Settings, then System, then About, and look at System type. If it says ARM-based processor, take the ARM download. Anything else, take the first one.

This page guesses for you where it can, and marks the one it thinks is yours.

Updating

Run the newer installer over the old one. Your records stay where they are. Uninstalling asks before it deletes anything, and keeps your records unless you say otherwise.
